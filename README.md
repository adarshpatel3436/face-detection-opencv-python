# Real-Time Face Detection using OpenCV (Python)

This project performs **real-time face detection** using a webcam with **OpenCV** and the **Haar Cascade classifier**.

It detects faces from the live camera feed and draws a **yellow bounding box** around each detected face.

---

## 🚀 Features
- Real-time webcam face detection
- Uses OpenCV's built-in Haar Cascade XML file
- Simple and beginner-friendly code
- Works on laptop/USB webcam

---

## 🛠️ Technologies Used
- Python 🐍
- OpenCV (`cv2`)
- Haar Cascade Classifier
